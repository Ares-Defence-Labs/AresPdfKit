# Changelog

## 2.0.0 — 2026-10-23

- Introduce one Flutter PDF SDK with typed low-level APIs and a configurable compiled viewer/editor.
- Add document creation/editing, forms, annotations, security and bounded DOCX/XLSX/PPTX conversions.
- Support offline cryptographic signatures, timestamp workflows and supplied CRL/OCSP evidence within the documented scope.
- Include eight spreadsheet scalar functions and host-owned import, signing and export callbacks.
- Verify offline signed licences, real shared trial expiry, retained readers and paid sandbox API/viewer operations.
- Preserve signed macOS framework layout through pub.dev using the Desktop 2.0.1 packaging patch.
- Correct Android 16 KB ELF/ZIP alignment; verify Samsung and iPhone native import/signing/export workflows.
- Include native Android/iOS/macOS/Windows/Linux members and Web Wasm runtimes.
- Document Windows runtime and macOS foreground UI as unverified in this version; full Syncfusion parity is deferred.
