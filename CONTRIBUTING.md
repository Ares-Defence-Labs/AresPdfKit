# Contributing

This public repository contains documentation/support material. Propose clear
documentation corrections with the affected guide and a sanitized reproduction.
Do not submit SDK binaries, implementation source, customer PDFs, secrets or
private account details. Feature requests should describe the intended workflow
and target platforms; a requested capability is not a current support claim.

SDK implementation and release pipelines are maintained in the private source
repository. No public workflow publishes a package from this documentation tree.
