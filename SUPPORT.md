# Support

Use [GitHub issues](https://github.com/Ares-Defence-Labs/AresPdfKit/issues) for
sanitized reproducible SDK questions. Include platform/OS/device, SDK and Flutter
versions, build mode, integration mode, error code and expected versus observed
behavior. Attach only synthetic documents you are authorized to share.

Use the [developer portal](https://aresdefencelabs.com/development-sdks?sdk=pdf-library&view=overview)
for account/billing/licence assistance. Do not share real licence strings in
public issues. Security reports follow [SECURITY.md](SECURITY.md).
